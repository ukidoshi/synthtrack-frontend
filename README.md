# SynthTrack — лабораторная работа № 5

Гостевой SPA для просмотра стадий многостадийного синтеза.
Стек — React 19, TypeScript, React-Bootstrap и Vite.

## Запуск

Node.js 20.19+ в ветке 20 или Node.js 22.12+. Из каталога фронтенда:

```bash
npm ci
npm run dev
```

Локальный адрес: `http://localhost:3000`. Команда `npm run build` проверяет TypeScript и собирает приложение в `dist/`. Команда `npm run preview` показывает сборку локально.

## Страницы и навигация

| Страница | Поля и информация | Действия |
| --- | --- | --- |
| Плитка (`#/stages`, стартовая) | Поля «Температура» (минимум в °C) и «Компоненты» (текст в названии или описании). На карточке видны фото, номер, название и температура. Карточки расположены в два столбца. | «Применить» или Enter показывает стадии с температурой ≥ порога. Пустые поля показывают все стадии. «Сбросить» очищает оба поля и возвращает все стадии. Нажатие на карточку открывает её в ленте. |
| Лента (`#/feed`, `#/feed/:id`) | Портретное видео с автозапуском без звука, название, температура, выход и число лайков. | «ПОКАЗАТЬ ВСЁ» раскрывает и сворачивает описание. «Далее» переключает видео по порядку, после последнего открывает первое. |

Нижняя панель содержит четыре пункта в порядке **Лента, Добавление, Плитка, Вход**. В гостевом интерфейсе доступны «Лента» и «Плитка». «Добавление» и «Вход» отключены. Счётчик лайков отображается для чтения.

## Данные и фильтрация

- `src/data/synthesisStages.ts` содержит тип и коллекцию mock-стадий. Данные и медиа загружаются из файлов фронтенда. При навигации и фильтрации запросов к API нет.
- Третья стадия имеет пустые `image_url` и `video_url`. `stageImage` подставляет `public/media/default-reaction.svg` для плитки и постера. `stageVideo` подставляет `public/media/default-reaction.mp4` для ленты.
- `App` хранит значения полей и применённые фильтры в `useState`. `StageGridPage` фильтрует коллекцию при рендере. `TemperatureFilter` получает значение и обработчики через props.
- `useEffect` в `App` подписывается на `hashchange` и снимает подписку при размонтировании. `useState` в `FeedStage` управляет видимостью описания.
