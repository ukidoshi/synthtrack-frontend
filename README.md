# SynthTrack — интерфейс химика

Гость просматривает стадии синтеза. После входа химик может поставить или снять лайк, создать черновик, опубликовать стадию и удалить собственную запись.

## Запуск

Запустите Docker Compose в каталоге бэкенда. Затем в каталоге фронтенда выполните:

```sh
npm ci
npm run dev
```

Откройте http://localhost:3000. Vite пересылает запросы с префиксом `/api` в Laravel на http://127.0.0.1 и с префиксом `/s3` в MinIO на http://localhost:9000. Другие адреса задаются переменными `SYNTHTRACK_API` и `SYNTHTRACK_S3` перед запуском Vite. Для отдельной проверки без сервиса можно задать `SYNTHTRACK_API` с адресом свободного локального порта.

## Страницы

| Страница | Данные и действия |
| --- | --- |
| Плитка | Фото, номер, название и температура. «Применить» передаёт нижнюю границу температуры в `filter_temperature` и текст поля «Компоненты» в `filter_desc` для поиска в названии и описании. «Сбросить» снимает ограничение. Карточка открывает ленту. При `is_owner = 1` химик может подтвердить удаление своей стадии. |
| Лента | Видео, постер, выход, температура, число лайков. «ПОКАЗАТЬ ВСЁ» раскрывает описание, «Далее» запрашивает очередную стадию. После входа доступен лайк. Для пустых медиа используются локальные файлы. |
| Добавление | Для нового черновика укажите название, при необходимости выберите фото и видео, нажмите «Далее». У сохранённого черновика заполните описание, выход и температуру и нажмите «Опубликовать». При повторном открытии страницы приложение загружает черновик текущего химика. |
| Вход | Email и пароль зарегистрированного химика. После успешного входа меню показывает «Выход». Выход отзывает JWT, очищает локальный токен и сбрасывает фильтр. |

## Состояние и запросы

Redux Toolkit хранит пользователя интерфейса, порог температуры и текст поля, список, текущую стадию, черновик и состояние запросов. После F5 Redux начинает с гостевого режима. JWT остаётся в localStorage под ключом `synthtrack.access_token`. Гостевые запросы выполняются без Bearer. Для проверки прав в Postman передайте сохранённый JWT как Bearer и выполните GET /api/synthesis-stages.

Доменные запросы выполняют thunk-функции из `src/store.ts` через сгенерированный Axios-клиент. Вход и выход вызывают Axios напрямую. Пока запрос выполняется, индикатор загрузки блокирует управление. При недоступном сервисе гостевые плитка и лента переходят на локальную подборку. В пользовательском режиме приложение показывает ошибку.

## Сборка и кодогенерация

```sh
npm run generate:api
npm run build
```

Контракт в `openapi/synthtrack.json` основан на Swagger бэкенда. Для генерации указаны читаемые operationId, обязательные поля ответов и отдельный маршрут первого элемента ленты. Результат генерации — `src/api/SynthTrack.ts`.
